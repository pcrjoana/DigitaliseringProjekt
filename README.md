
# Digitalisering Projekt

This is a digitalisation project for the digitalisation course of the MSc in Library and Information Science at the [University of Borås](https://www.hb.se/).
This project used a template that designed by  [Wout Dillen](https://github.com/WoutDLN), who is a senior lecturer at the University of Borås, to help students of the Digitising Cultural Heritage Materials (DCHM) course at the University of Borås publish their digitisation projects online with GitHub Pages.
